# dmart-sales-dashboard-2025-Linkedin-Integrated-
End-to-end DMart 2025 retail analytics project: data extraction, data cleaning and data manipulation on 2,500 transactions, followed by descriptive analysis, KPI tracking and interactive dashboard building using Excel, HTML, CSS and JavaScript. Features cross-filtering charts, sales, profit and margin insights. Built by Yash Sandeep Bhagyawant.
